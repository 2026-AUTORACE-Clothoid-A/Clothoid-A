방지턱 / 정지선 전용 Qt 시각화 (namgyu/bump, Docker)

호스트에서 실행:
  python3 tools/bump_viewer/run.py
  python3 tools/bump_viewer/run.py bag/bag_1111_035527

Docker 안에서 직접 실행:
  source /opt/ros/humble/setup.bash
  cd /home/user/Clothoid-A
  source ros2_ws/install/local_setup.bash
  OPENBLAS_NUM_THREADS=1 python3 tools/bump_viewer/viewer.py bag/bag_1111_035527

원본 카메라 / 현재 차선 BEV / 정지선 BEV / 실제 정지선 흰색 마스크 /
현재 차선 노란색 마스크 / HSV 채널을 함께 보여 줍니다.
마우스로 영상 픽셀의 H/S/V 값을 확인하고 HSV 보기에서 채널을 바꿀 수 있습니다.
하늘색은 정지선 검사 영역, 자홍색은 검사에서 선택된 횡방향 정지선 후보입니다.
주황색은 별도로 추적한 미션 시작선입니다. 위쪽에 시작선 상태/앞바퀴까지 남은 거리와
횡단보도 정지선 상태/정지 목표까지 남은 거리를 따로 표시합니다.

현재 코드로 재계산: 작업 폴더의 Python 코드와 YAML을 다시 읽습니다.
미션과 차선은 실제 MissionNode/LaneMainNode 콜백을 사용하며 미션 타이머는 20Hz로 재생합니다.
미션의 rate_hz를 바꾸면 재생 타이머도 그 값을 따릅니다.
노드가 만드는 차량 명령은 모두 메모리 안에서 캡처합니다. executor를 실행하지 않습니다.
별도 localhost ROS 도메인 229를 사용합니다. 차량의 주행 토픽으로 출력하지 않습니다.

위쪽 상태와 초록 이벤트/속도는 현재 코드 재계산, 주황 이벤트/속도는 백에 기록된 값입니다.
YOLO는 백의 /detections를 사용합니다. 모델을 다시 추론하지 않습니다.
압축 영상으로 차선을 재계산하면 실제 raw 입력과 JPEG 픽셀 차이가 있을 수 있습니다.
흰색 마스크/정지선 BEV는 미션 비활성 구간도 살펴보는 상시 미리보기입니다.
미리보기에 선이 보인다고 차량이 그 선에서 멈춘다는 뜻은 아닙니다.
실제 활성 여부와 남은 거리는 위쪽 정지선 상태에서 확인하세요.
방지턱의 외형을 HSV로 검출하는 기능은 현재 주행 코드에 없습니다.
방지턱은 표지판 확정 + IMU pitch 상태로 판단하고, HSV는 차선/정지선 검사를 보여 줍니다.

Space 재생/정지, 좌우 한 프레임 이동, 이벤트 클릭 또는 시간 그래프 클릭으로 이동합니다.
방지턱 표지판 / 최대 기울기 버튼으로 관심 구간에 바로 갈 수 있습니다.
백 끝에서 멈추며 자동 반복하지 않습니다. 현재 화면 저장으로 PNG를 남길 수 있습니다.
CameraInfo 등 입력이 없으면 경고를 표시하며, 거리/미션 결과를 정상 검증한 것으로 취급하지 않습니다.
콜백 수신 순서는 bag 수신 시간 순이며 실제 ROS 스케줄과 차이가 있습니다.
이전 상태에서 따온 bag으로 새 제어의 실제 움직임까지 검증할 수는 없습니다.
