# 정적 회피 벤치마크

차로 순서 계획기(`lane_sequence.py`, `sequence: true`, 기본값)와 그 전 방식인 1단 계획기(`sequence: false`)를 같은 조건에서 비교한 기록이다. 새 설정을 시험하면 같은 명령으로 돌려 아래에 행을 추가한다.

- 코드 기준: `db3fddf` (차로 순서 계획기 추가). 시뮬레이터 결과는 이 커밋을 빌드한 설치본으로 돌렸다.
- 표지판: 왼쪽 = A = 1차선, 오른쪽 = B = 3차선
- 차로 순서: 회피 중 차가 지나간 차로. 예: 2-1-2-3 = 1차선으로 피했다가 3차선으로 들어감

## 판정 기준
한 판은 아래 중 하나라도 해당하면 실패로 센다.

| 표시 | 뜻 |
|---|---|
| 충돌 | LIMO에 닿음 (시뮬레이터는 자체 충돌 판정 포함) |
| 근접 | LIMO와 3 cm 이내 |
| 섬 | 섬 몸체를 밟음. 앞끝 뾰족한 부분 0.25 m만 걸친 경우는 실패가 아니라 "섬 끝"으로 따로 센다 (2026-11-10 결정) |
| 교착 | 시간 안에 끝 지점까지 못 감 |
| 차로 | 끝에서 표지판 차로가 아님 |

"여유"는 판 동안 차와 LIMO 사이의 최소 거리다.
