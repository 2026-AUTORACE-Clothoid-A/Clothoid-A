## 1. 화이트밸런스 (가장 중요)
4 s 간격으로 화면 아래쪽 가운데(바닥) 중앙값을 봤다. 회색 바닥이면 B≈G≈R이어야 한다.

| 시각(01) | 장면 | 바닥 B/G/R |
|---|---|---|
| 0~36 s | 출발, 직선, 지그재그 | 30~65로 밝기는 달라도 B≈G≈R |
| 40~72 s | 3차선 장애물, 갈림길(장애물 콘) | 66/65/56 ~ 64/55/45, 약하게 쏠림 |
| **80~92 s** | **라바콘 구간** | **59/58/41 → 79/74/38 → 69/66/33** |
| 96 s~ | 콘을 지난 뒤 | 다시 B≈G≈R |

- 다른 bag의 라바콘 구간에서도 바닥을 재 보면 같은 쏠림이 있다: 02 80~84 s 74/69/34·60/58/31, 03 60 s 80/75/34, 04 60~64 s 68/66/42·75/71/34.
- 대회에는 신호등(빨강·노랑·초록)이 있다. 화면에 빨간 물체가 많아지면 신호등 색 판단이 흔들릴 수 있다.

## 2. 자동 노출
- 화면 전체 평균 밝기는 bag 4개 모두 5~95 백분위가 105~122다. 카메라가 화면 평균을 맞추고 있다는 뜻이다.
- 그 대신 같은 회색 바닥의 밝기가 30(24 s 코너)에서 79(콘 구간)까지 바뀐다.
- 기존 문서 기록: 어두우면 fps가 약 12 Hz로 떨어진다(노출 시간이 늘어서로 추정, `MIGRATION_PLAN.md` B3/B6, `FIELD_TEST.md`).

## 3. 흐림
- 선명도는 그레이 영상의 라플라시안 분산이다. 장면의 무늬 양에도 영향을 받으므로 대략적인 지표다.
- 직선 1000~1450 / 코너(24 s) 520 / 콘 구간(84~92 s) 370~580.
- 코너에서 떨어지는 것은 회전 중 모션 블러로 보인다. 노출을 고정할 때 노출 시간을 짧게(대신 게인을 올려) 잡는 근거가 된다.

## 4. 프레임 끊김
- 이미지는 29.8~30 Hz로 대체로 안정적이다.
- 0.2 s 넘게 끊긴 경우:
  - 01 33.6 s: 0.67 s, 이미지만
  - 04 1.4 s: 0.38 s, 모든 토픽이 같이 끊겨 녹화·시스템 쪽 정지로 보인다
  - 04 91.9 s: 0.21 s
- `camera_info`는 0.2 s 넘는 간격이 bag마다 수십 번 있다(`image_raw`는 정상). `camera_info`와 동기화해서 받는 노드가 있으면 영향을 받는다.
- 보행자 구간에서 0.67 s 끊김이 한 번 났다. 대회 주행에서 같은 일이 생기면 보행자 정지 판단이 늦어진다. Jetson에서 YOLO와 함께 돌릴 때 다시 잰다(`full.launch.py use_latency_monitor:=true`).

## 제안: WB·노출 고정
1. **Jetson에서 파라미터 이름 확인.** 저장소와 이 PC에는 `orbbec_camera` 패키지가 없다(`~/wego_ws`에 있음).
   ```bash
   ros2 param list /camera/camera | grep -iE 'white|exposure|gain|auto'
   ros2 param describe /camera/camera <이름>
   ```
   런타임에 바꿀 수 있는지(`ros2 param set`)도 같이 본다. 안 되면 launch 인자로 넘긴다.
2. **대회장 조명에서 값 잡기.** 회색 바닥과 흰 선이 보이는 곳에서 자동 상태로 몇 초 둔 뒤, 그때 값을 읽어 고정값으로 쓴다.
   - WB: 고정
   - 노출: 고정. 흐림 때문에 노출 시간은 짧게, 대신 게인을 올린다. 단, 30 fps가 유지되는지 확인한다.
3. **bringup에 인자로 넣기.** `bringup.launch.py`의 카메라 include에 WB·노출 인자를 추가한다(통합 쪽에서 한다. 이름과 값만 알려 주면 된다). 지금 차와 대회장 값을 따로 둘 수 있게 launch 인자로 만든다.
4. **전후 비교.** 같은 코스를 고정 전후로 녹화해서 아래 세 가지를 비교한다. 콘 구간 바닥 B/G/R, 장면별 바닥 밝기 범위, 코너 선명도. 계산은 아래 스니펫으로 한다. 2025 회고(`2025_retrospective.md`)에도 "대회장 도착하면 노출·WB 조정"이 남아 있으므로 현장 절차에 넣는다.

```python
# tools/offline_pipeline 에서: python3 -c "..." 로 실행
from bagio import read, image_bgr; import numpy as np, cv2
t0 = None
for _, t, m in read(BAG, ['/camera/color/image_raw'], every={'/camera/color/image_raw': 15}):
    t0 = t if t0 is None else t0; b = image_bgr(m); h, w = b.shape[:2]
    floor = np.median(b[int(h*.85):, int(w*.3):int(w*.7)].reshape(-1, 3), 0)          # 바닥 B,G,R
    sharp = cv2.Laplacian(cv2.cvtColor(b, cv2.COLOR_BGR2GRAY), cv2.CV_64F).var()   # 선명도
    print(f'{t-t0:6.1f} floor {floor} sharp {sharp:.0f}')
```
